Flagged for Review

This page lists every claim made about this rebuild together with the official source it was checked against, and every value or behaviour that could not be confirmed. Nothing on this page is inferred: where an official source does not publish a value, the cell is left blank and the row is marked unverified.

Status of the site: the uploaded repository contained the pages, README and server but none of the front-end assets (assets/css/style.css and the eight assets/js/*.js files). The original upstream repository that hosted them (buffedlizard55-lab/MLB-Live-PBP) returns 404 from the GitHub API, so the assets were reconstructed from the contract the pages and README define, then verified with a network-free test harness (tools/smoke-test.mjs) against payload shapes captured from the live StatsAPI. The pages, class names, element ids, globals, endpoints, polling cadences and feature set are unchanged.

4. What was checked, and how

  • Payload shapes: each parser was written against a response fetched from statsapi.mlb.com on 2026-11-20 (links in table 1) — schedule, gameStatus, eventTypes, playByPlay for a game with four real review events (ABS MJ overturned, MD stands, MA overturned, umpire NA), and feed/live for review/ABS counters.
  • Behaviour: tools/smoke-test.mjs boots index.html, game.html, reviews.html in jsdom with the real scripts and asserts on the rendered DOM: game cards, review chips, header, at-bat module, linescore, play-by-play, box score, review tab, review banner, feed rows, filters, persistence and the model's clamp/tier/driver output. It also asserts every local href/src on every page resolves to a real file.
  • Links: every link on this site is either relative (verified by that test) or points at statsapi.mlb.com, mlb.com or mlbstatic.com.
  • Not verified here: the live behaviour of the public API in your browser, and the image hosts. The build sandbox can only reach a small allow-list of hosts, so any live-API claim above rests on a single fetched response per endpoint, not on a long observation window.
